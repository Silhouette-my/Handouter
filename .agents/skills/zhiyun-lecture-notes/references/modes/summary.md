# Mode · summary

Create a fast-reading summary that preserves the conditions behind important conclusions.

- After the upfront assessment callout (when applicable) and folded course information, start the main text with `## 本讲速览` containing roughly 5–10 genuinely important points.
- Then organize the lecture into a small number of themes, usually 3–8. summary is the only mode permitted to regroup the actual lecture sequence.
- Use one time/source fold per main chapter, not per natural paragraph; list separate real intervals for combined passages. The upfront callout must still preserve supported assignments, quizzes, exams, group tasks and grading constraints. Put any final unresolved checklist in one closed `待核对` fold.
- Compress repeated examples and secondary elaboration, but retain critical formulas, numbers, exceptions, conditions, and negations.
- Do not invent exam points, assignment requirements, or unsupported takeaways.
- Default to text and compact lists. Avoid decorative Mermaid/ASCII diagrams or long timelines unless they are clearly the simplest representation.
- Target a note that can usually be reviewed in about 5–10 minutes; material density may justify some variation.
