# Execution · long course

For long lectures, completeness must be managed explicitly.

- Inspect the source index/segments first and divide the lecture into manageable chronological ranges. Record topic boundaries without regrouping distant passages; only summary may later reorder the body by theme.
- Process every range; keep a lightweight internal checklist so the middle of the lecture is not skipped when context grows.
- Revisit ambiguous terms only after collecting nearby transcript/PPT evidence; do not stall the entire task on one uncertain word.
- Preserve beginning, middle, and ending material, including late administrative/course requirements if they are part of the requested lecture.
- If context or execution limits prevent full coverage, stop claiming completion and state the unprocessed range clearly.
